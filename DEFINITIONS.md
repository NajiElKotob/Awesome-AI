# Definitions

* Artificial intelligence (AI) is the field of building computer systems that perform tasks we'd normally consider to require human intelligence – things like recognizing speech, understanding language, solving problems, and making decisions.
* Data – The recorded facts, measurements, text, images, or signals that an AI system learns from and operates on.
* Algorithm – A set of step-by-step instructions for performing a task, such as processing data or training a model.
* Machine learning – A method in which a system learns patterns from data rather than following explicitly programmed rules. Its main forms are supervised, unsupervised, and reinforcement learning.
* Model – The output of training an algorithm on data. It stores the patterns found during training and applies them to new inputs.
* Feature – A single measurable attribute of the data, such as a person's age or a pixel's brightness.
* Feature extraction – Transforming raw data into a smaller, more informative set of features.
* Feature engineering – Selecting, combining, and reshaping features to make patterns in the data easier for a model to detect.
* Prediction – Estimating an unknown value from known inputs.
* Classification – A type of prediction in which the output is a category rather than a quantity.
* Neural network – A model built from interconnected nodes arranged in layers, loosely inspired by the brain.
* Training and testing – Training is fitting a model to one portion of the data; testing is measuring its performance on a separate portion it has not seen.
* Overfitting – When a model fits its training data so closely that it performs poorly on new data.
* Underfitting – When a model is too simple to capture the patterns in the data.
* Optimization – Adjusting a model's internal parameters to minimize its errors.
