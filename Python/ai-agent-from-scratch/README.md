# Build an AI Agent from Scratch


Build a functional AI agent step by step using Python, a hosted LLM API, and real business data. Starting with a simple LLM interaction, progressively implement tool calling, tool execution, and the agent control loop from scratch - without agent frameworks.

Using a sales CSV as the business scenario, learn how an LLM interprets user requests, selects tools, receives execution results, and produces evidence-based answers.

The project emphasizes deep conceptual understanding, transparent implementation, and line-by-line explanations of how AI agents work.

Technologies: Python, OpenAI API, pandas, CSV.

Learning outcome: Understand and build a tool-calling AI agent from the ground up, including its core architecture, execution loop, and essential safeguards.
